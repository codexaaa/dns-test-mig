⚡ dns-test
Your connection deserves the best path.

dns-test is a powerful and intuitive tool designed for developers and power users seeking maximum network performance. It performs real-time latency analysis on the world's leading DNS providers (such as Google, Cloudflare, and Quad9), allowing you to identify and apply the fastest configuration for your specific location with a single click.

Highlights:

🚀 High Precision: Real-time, multi-language ping tests.

🛠️ Instant Setup: Configure your environment in seconds via the terminal.

🐧 Linux Focused: Native support for Pop!_OS, Ubuntu, Mint, Zorin, and other Debian-based distributions.

Command: curl -sL https://raw.githubusercontent.com/codexaaa/dns-test-mig/main/install.sh | bash
