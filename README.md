DNS Test is a lightweight terminal utility designed for Linux users to optimize their internet connection latency. It automatically tests the response time of the world's most popular DNS providers and allows you to apply the fastest one with just a few keystrokes.

✨ Features
Real-time Latency Testing: Pings multiple DNS providers (Google, Cloudflare, OpenDNS, etc.) to find the lowest latency in milliseconds.

Interactive TUI: Features a clean, easy-to-use terminal interface for selecting and applying changes.

Instant Application: Uses nmcli to safely update your NetworkManager settings without needing to manualy edit configuration files.

English Language Support: Clean and accessible interface for global users.

🚀 Quick Install
To install and start using DNS Test Mig immediately, just run the following command in your terminal:

Bash
curl -sL https://raw.githubusercontent.com/codexaaa/dns-test-mig/main/install.sh | bash
🛠️ How to Use
After installation, simply type the command below in your terminal:

Bash
dns-test-mig
